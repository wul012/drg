## DRG入组规则匹配流程
DRG 入组会从 CHS_DRG_20/ 查询规则文件
CHS_DRG_20/ 规则文件下载地址：[DRG_Rules/CHS_DRG_20 at main · OpenDRG/DRG_Rules](https://github.com/OpenDRG/DRG_Rules/tree/main/CHS_DRG_20)

#### 一、规则加载

调用 `load_chs_rules()` 一次性加载全部分组规则文件，构建内存索引。

| 文件路径              | 存储内容                    |
| :-------------------- | --------------------------- |
| CHS_DRG_20/MDC.dat    | MDC 编码、名称对照          |
| CHS_DRG_20/ADRG.dat   | ADRG 编码、名称对照         |
| CHS_DRG_20/DRG.dat    | 最终 DRG 编码、组名对照     |
| CHS_DRG_20/MCC.dat    | 严重合并症 / 并发症诊断列表 |
| CHS_DRG_20/CC.dat     | 普通合并症 / 并发症诊断列表 |
| CHS_DRG_20/CCE.dat    | CC/MCC 排除诊断列表         |
| CHS_DRG_20/MDC/*.dat  | 主诊断编码 → MDC 映射关系   |
| CHS_DRG_20/ADRG/*.dat | 主手术编码 → ADRG 映射关系  |

#### 二、分步入组逻辑

1.**主诊断匹配 MDC**

函数：`match_mdc(primary_diagnosis_code)`

- 逻辑：根据**主诊断编码**，查询 `CHS_DRG_20/MDC/` 下对应数据文件，匹配得到 MDC 编码。
- 示例：`A01.002+G01*` → 匹配 `MDCB_神经系统疾病及功能障碍.dat` → 结果：`MDCB`

**2.主手术匹配 ADRG**

函数：`match_adrg(mdc_code, procedure_code)`

- 约束：以已匹配的 `MDC` 限定 ADRG 大类，优先匹配同前缀 ADRG。
- 逻辑：根据**主手术编码**，查询 `CHS_DRG_20/ADRG/` 下对应数据文件，匹配得到 ADRG 编码。
- 示例：`38.1000x002` → 匹配 `BB1_神经系统复合手术.dat` → 结果：`BB1`

**3.次要诊断判定 CC/MCC 等级**

函数：`detect_complication_level(次要诊断编码列表)`

判定顺序（优先级从高到低）：

1. 检索 `CCE.dat`：若命中排除列表 → 直接判定为**无 CC/MCC**
2. 未排除则检索 `MCC.dat`：命中 → 判定为 **MCC**
3. 未命中 MCC 则检索 `CC.dat`：命中 → 判定为 **CC**
4. 全部未命中 → 判定为**无 CC/MCC**

- 示例：`J96.0` 规范化为标准编码 `J96.000`，未命中 `CCE.dat`、命中 `MCC.dat` → 判定为 **MCC**

**4.生成最终 DRG 编码**

函数：`build_drg_code(ADRG编码, 合并症等级)`

1. 基础映射规则（简化规则）
   - 伴 MCC：`ADRG编码 + 后缀1`
   - 伴 CC：`ADRG编码 + 后缀3`
   - 无 CC/MCC：`ADRG编码 + 后缀5`
2. 合法性校验：查询 `DRG.dat`，若基础规则生成的编码不存在，按优先级 `9 → 5 → 3 → 1` 向下检索库内已存在的 DRG 编码。

- 示例：`BB1` + MCC → 基础编码 `BB11`，校验 `DRG.dat` 存在该编码 → 最终 DRG：`BB11 神经系统复合手术，伴严重合并症或并发症`

#### 三、整体流程汇总

`加载规则` → `主诊断匹配MDC` → `主手术+MDC匹配ADRG` → `次诊断判定CC/MCC等级` → `结合等级生成最终DRG`

## 需求文档生成

需求文档生成改为直接调用LLM生成文档。

已将“项目需求分析阶段”的大模型生成逻辑单独封装进 `requirement_analysis_generation.py` 。它会向 DeepSeek 发送 HTTP 请求，使用 deepseek-v4-flash 模型，并要求模型返回结构化 JSON，生成：

- 需求分析文档：系统功能需求、用例等
- 架构设计文档：整体结构、模块关系等
- 测试文档：测试策略、测试方案、测试用例

**密钥配置**：需要将 `deepseek_config_example.py` 文件复制并改名为 `deepseek_config.py`，并填写真实 API Key。

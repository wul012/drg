## 1. 项目背景与目标

### 1.1 项目背景

DRG（Diagnosis Related Groups，疾病诊断相关分组）是医保支付改革的核心工具。医院需要根据患者的主要诊断、手术操作、合并症/并发症等信息，将住院病例归入对应的 DRG 分组，从而确定医保支付标准。

当前 DRG 入组工作存在以下痛点：

- 入组规则复杂，人工判断效率低、易出错
- 入组结果缺乏可解释性，医生难以理解分组依据
- 病例管理、文档生成、测试验证等环节缺乏协同
- 移动端场景（如查房上报）缺少系统支持

### 1.2 项目目标

构建一个教学演示级的"医保DRG智能协同平台"，实现以下目标：

1. **自动入组**：根据病例诊断和手术信息，自动完成 MDC → ADRG → DRG 分组
2. **可解释性**：每次入组结果附带自然语言说明，解释分组依据
3. **多角色协作**：支持管理员、医生、分析员多角色操作，模拟多 Agent 协同
4. **文档闭环**：需求分析、文档生成、测试用例、提交记录全流程自动化
5. **移动端支持**：提供移动端上报和消息同步能力
6. **本地可运行**：不依赖外部 API，单机即可完整运行和演示

## 2. 系统范围与边界

### 2.1 系统范围

本系统覆盖以下业务范围：

| 范围 | 说明 |
|---|---|
| 用户管理 | 注册、登录、退出、角色分配 |
| 需求分析 | 项目信息录入、需求分析内容生成 |
| 病例管理 | 病例录入、筛选、排序、分页、撤销 |
| DRG 入组 | 自动分组、入组原因生成、风险评估 |
| 文档管理 | 文档自动生成、浏览、下载 |
| 测试管理 | 测试用例自动生成、重新生成 |
| 提交管理 | 提交批次生成、提交记录留痕 |
| 多 Agent 协作 | Agent 状态管理、消息流同步 |
| 移动端 | 首页、上报、消息、文档四个移动页面 |
| 仪表盘 | DRG 入组分布可视化、项目指标展示 |

### 2.2 系统边界

本系统**不包含**以下内容：

- 真实国家医保 DRG 分组器（本系统为教学版简化规则）
- 完整 ICD-10 / ICD-9-CM-3 编码库
- 外部 LLM API 调用（使用本地微型 LLM 替代）
- 多用户并发和分布式部署
- 真实医疗数据和患者隐私保护
- 医保费用结算和支付标准计算

## 3. 用户角色与权限

### 3.1 角色定义

系统支持三种用户角色：

| 角色 | 标识 | 说明 |
|---|---|---|

| 功能 | 管理员 | 医生 | 分析员 |

| 病例筛选与查看 | ✓ | ✓ | ✓ |
| 病例撤销 | ✓ | ✗ | ✗ |

| 提交操作 | ✓ | ✓ | ✓ |
| 移动端上报 | ✓ | ✓ | ✓ |
| 仪表盘查看 | ✓ | ✓ | ✓ |

- 使用 `role_required` 装饰器进行路由级权限控制

## 7. DRG 入组规则规格

### 7.1 规则覆盖范围

当前教学版规则覆盖 8 个 MDC 大类：

| MDC 编码 | 名称 | 诊断前缀示例 | 外科 ADRG | 内科 ADRG |
|---|---|---|---|---|
| MDCB | 神经系统疾病及功能障碍 | G01, I60, I61, I63 | BB1 | BZ1 |
| MDCA | 呼吸系统疾病 | J18, J44, J96, J12 | AB1 | AZ1 |
| MDCD | 消化系统疾病 | K35, K36, K80, K81 | GD1 | GZ1 |
| MDCG | 消化道疾病及功能障碍 | C16 | GB2 | GZ2 |
| MDCH | 肝胆胰疾病及功能障碍 | K83 | HC1 | HZ1 |
| MDCF | 内分泌代谢系统 | E10, E11, E14 | KD1 | KZ1 |
| MDCE | 循环系统疾病 | I20, I21, I25, I50 | FB1, EC2 | FZ1 |
| MDCL | 泌尿系统疾病 | N17, N18, N20, N39 | LB1 | LZ1 |

### 7.2 入组流程

```text
主诊断编码 → match_mdc() → MDC 疾病大类
                                ↓
MDC + 主手术编码 → match_adrg() → ADRG 诊疗组
                                       ↓
次诊断编码列表 → detect_complication_level() → CC/MCC 等级
                                                    ↓
ADRG + CC/MCC → build_drg_code() + build_drg_name() → DRG 编码 + 名称
                                                            ↓
                                              generate_drg_reason() → 入组原因说明
```

### 7.3 并发症等级判断规则

| 等级 | 含义 | DRG 编码后缀 | 风险等级 |
|---|---|---|---|
| MCC | 严重合并症或并发症 | 1 | 高 |
| CC | 一般合并症或并发症 | 3 | 中 |
| 无CC/MCC | 无合并症或并发症 | 5 | 低 |

### 7.4 兜底机制

| 场景 | 兜底结果 | 状态 | 风险等级 |
|---|---|---|---|
| 主诊断未命中任何 MDC | MDCQ 未细分教学演示大类 | 需复核 | 高 |
| 手术未命中且无兜底组 | QZ1 未细分教学演示组 | 需复核 | 高 |
